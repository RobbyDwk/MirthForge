# MirthForge

MirthForge is a cloud-based platform providing real-time data processing capabilities with auto-scaling support for scalable, on-demand data management.

MirthForge is aimed at developers who need a straightforward, dependable solution.

## Installation

1. Clone the repository: `git clone https://github.com/irenascent/MirthForge.git`
2. Install required dependencies: `pip install -r requirements.txt`

## Configuration

To configure MirthForge, modify the settings in the configuration file. Options include:
- **DEBUG**: Enable or disable debug mode.
- **ALLOWED_HOSTS**: Set allowed hostnames.
- **DATABASES**: Configure database settings.
